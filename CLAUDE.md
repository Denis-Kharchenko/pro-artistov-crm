# CRM для продюсерского центра «Про Артистов»

Все файлы проекта лежат в `pro-artistov-crm/`:
- `PRODUCT.md` — о заказчике и задачах CRM.
- `DESIGN.md` — дизайн-система (цвета, шрифты, компоненты).
- `design/` — HTML-макеты страниц, общие стили и скрипт в `design/assets/`.

## Скиллы для дизайна HTML-страниц
При любой работе над интерфейсом использовать:
1. `impeccable` — основной: направление, крафт, аудит, полировка (`critique`, `audit`, `polish`, `layout`, `typeset`).
2. `ui-ux-pro-max` — правила UX, доступности, состояний, графиков.
3. `ckm:design-system` — токены (primitive → semantic → component), спецификации компонентов.
4. `design-taste-frontend` — антишаблонные правила (без длинных тире, без «эйброу», без фейковых скриншотов).
5. `dataviz` — для графиков и цифровых показателей.

Перед правками читать `pro-artistov-crm/DESIGN.md`, новые цвета и размеры добавлять только через токены в `app.css`.
Язык интерфейса русский. Данные в макетах демонстрационные.
